# Plan UI Personal Document Management System

## Yang akan dibangun
- Mengubah halaman utama menjadi dashboard penyimpanan dokumen yang siap dipakai sebagai prototipe UI.
- Mengikuti referensi neobrutalism profesional: garis hitam tebal, bayangan tegas, warna kuning-lilac-hijau yang seimbang, dan tipografi geometris.
- Menampilkan navigasi samping, pencarian, ringkasan penyimpanan, folder, daftar file terbaru, serta panel detail/aktivitas.
- Menambahkan visual kucing sebagai identitas produk tanpa mengurangi keterbacaan dashboard.
- Membuat interaksi UI dasar seperti pencarian, pilihan tampilan, menu akun, favorit, dan tombol unggah tanpa menyambungkan penyimpanan atau login.
- Menyesuaikan tampilan desktop dan smartphone serta menambahkan metadata halaman.

## Teknis
- Menggunakan React/TanStack dan Tailwind yang sudah tersedia.
- Seluruh warna, bayangan, radius, dan font didefinisikan sebagai token desain global.
- Gambar kucing disimpan sebagai aset aplikasi dan dipakai secara responsif.
- Memastikan halaman lolos pemeriksaan build dan alur tampilan utama diuji di desktop serta smartphone.

## Batas tahap ini
- Hanya UI dan interaksi presentasi; database, autentikasi, unggah nyata, dan penyimpanan cloud belum diaktifkan.
